# NITROVA — GitHub Pages

Public, static Porsche gallery and interactive image studio. The site is served at `https://astraone11.github.io/` after GitHub Pages is enabled.

This repository contains only the files needed for the public Pages site: HTML, CSS, JavaScript, and six Porsche images. No credentials, server source, or database data are included.

Account and favorites links open the original NITROVA site at `https://nitrova-porsche.xboxsteam94.chatgpt.site/`, where those server-backed features currently run. The studio is an interactive high-resolution image presentation, not a rotatable 3D model.
