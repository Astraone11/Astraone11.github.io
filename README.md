# NITROVA — GitHub Pages

Public automotive catalog at https://astraone11.github.io/. This repository is the static presentation layer of NITROVA. It includes interactive search, filters, detail dialogs, an image studio, and cinematic scroll effects. Authentication and Porsche favorites still run at https://nitrova-porsche.xboxsteam94.chatgpt.site/; links to them remain intact. GitHub Pages cannot run that server backend.

The homepage now uses the supplied Porsche 911 Turbo GLB as a real-time Three.js hero. To keep the model deployable through GitHub Pages, the original GLB bytes are losslessly gzip-compressed, split into small text chunks, reconstructed in the browser, and passed directly to `GLTFLoader.parse`. It supports drag/swipe orbit, mouse-wheel or pinch zoom, smooth front/side/rear/top camera presets, scroll-directed camera motion, animated wheels, metallic environment reflections, and a reversible wheel engineering view. A compressed automotive video provides low-opacity atmosphere behind the WebGL layer. The Mission X image remains as a fallback when WebGL or the model cannot load. Rendering quality, shadows, and pixel ratio are reduced on mobile, while reduced-motion preferences disable automatic camera movement.

The current art direction uses a white and ice-blue automotive studio system inspired by the supplied reference film. BMW and Koenigsegg catalogue photography is presented through optimized transparent WebP cutouts, while the 3D Porsche uses softened studio lights, a neutral reflective floor, and a continuous spline-based camera path.

The original six Porsche entries remain. Nine additional image-led entries use the supplied Koenigsegg and BMW photos. Three Agera R entries are different visual treatments of one model, not three separate production models. The concept study is not identified as a production car. Unverified specifications show “Belum diverifikasi” rather than invented numbers. The multi-car showroom still pans and zooms supplied images; the dedicated Porsche 911 hero is the interactive 3D viewer. No source image has been artificially upscaled to 4K.

Published specification references: [Koenigsegg Agera R](https://www.koenigsegg.com/model/agera-r), [BMW M4 Competition](https://www.bmw-m.com/en/all-models/overview-m-and-m-performance/bmw-m4-coupe/2024/bmw-m4-coupe-and-bmw-m4-competition-coupe.html), and [BMW i7 M70 xDrive](https://www.press.bmwgroup.com/latin-america-caribbean/article/detail/T0413600EN/the-bmw-i7-m70-xdrive?language=en). Figures can vary by market, year, tires, and optional equipment.
